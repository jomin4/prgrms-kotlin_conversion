# step-57: 소스코드 폴더를 java에서 kotlin으로 이동

- 강의 링크: https://www.slog.gg/p/14128#57강
- 상태: 완료 (자연스럽게 선반영됨, 추가 작업 없음)

## 요구사항 요약

강사 원본은 6강부터 56강까지 `.kt` 파일을 계속 `src/main/java` 폴더 안에 둔 채로 진행하다가, 이 강에서야 `src/main/kotlin`으로 폴더 전체를 이동한다. 우리 프로젝트는 6강에서 "코틀린 전용 폴더를 만들자"는 판단으로 **처음부터 모든 `.kt` 파일을 `src/main/kotlin`에 생성**해왔기 때문에, 이 강에서 별도로 이동할 게 없다.

`find back/src/main/java -type f`로 확인한 결과 자바 파일이 완전히 0개.
