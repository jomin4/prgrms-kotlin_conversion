# step-59: Claude Code 시작, CLAUDE.md 생성

- 강의 링크: https://www.slog.gg/p/14128#59강
- 상태: 완료

## 요구사항 요약

강사 원본 강의는 Claude Code를 새로 설치하고 `/init` 명령으로 프로젝트를 분석한 `CLAUDE.md`를 자동 생성한 뒤, 불필요한 내용을 걷어내고 한글로 번역하는 과정을 보여준다.

이 세션은 이미 Claude Code로 진행 중이므로, `/init`이 하는 일(프로젝트 구조·빌드 명령·아키텍처를 분석해 향후 세션이 참고할 문서를 만드는 것)을 직접 수행해서 프로젝트 루트에 `CLAUDE.md`를 작성했다.

## 작성 내용

- 프로젝트 개요(백엔드/프런트엔드/문서 폴더의 역할)
- 빌드/테스트 명령어(`./gradlew compileKotlin ...`, `./gradlew test`, `pnpm dev` 등)
- 빌드 스택 요약(Spring Boot 4.1.0, Kotlin 2.2.20, JVM 24 타겟 고정 이유, Jackson 3.x 등)
- 도메인 패키지 구조 개요
- **이 저장소 특유의 작업 규칙**: `PROMPT.md`/`RULES.md`를 먼저 참고할 것, `@Jvm*` 어노테이션은 grep 감사 후 결정할 것(R-065), 커밋 전 컴파일 확인 등

처음부터 "필요없는 내용 제거 + 한글 번역"이 끝난 상태로, 범용 보일러플레이트 설명 없이 이 프로젝트에 실제로 쓸모 있는 내용만 한글로 작성했다.
